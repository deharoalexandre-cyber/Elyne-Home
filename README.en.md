# Elyne Home

**Languages: English · [Français](README.md)**  
**Catalog status: Proof of concept**

A local home assistant combining voice interaction, memory, observation, and home controls on a network managed by the user.

## Presented capabilities

- Local interaction, with proactive functions enabled by the user.
- Architecture envisaged for cameras and home automation on separate network segments.
- Actions designed to be traced and explained.

## Scope

Elyne Home is listed as a proof of concept on the website. Hardware and protocol integrations must be verified per installation; this repository certifies no particular Zigbee, Z-Wave, Matter, or camera compatibility.
