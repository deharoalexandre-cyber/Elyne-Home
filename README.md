# Elyne Home

**Langues : Français · [English](README.en.md)**  
**Statut affiché au catalogue : POC**

Un assistant domestique local qui réunit interaction vocale, mémoire, observation et commandes d'habitat dans un réseau maîtrisé par l'utilisateur.

## Capacités présentées

- Interaction locale, avec fonctions proactives activées par l'utilisateur.
- Architecture envisagée pour caméras et domotique sur segments réseau séparés.
- Actions conçues pour être tracées et expliquées.

## Périmètre

Elyne Home est présenté comme POC sur le site. Les intégrations matérielles et protocolaires doivent être vérifiées pour chaque installation ; ce dépôt ne certifie aucune compatibilité Zigbee, Z-Wave, Matter ou caméra particulière.
