# Evidence and limitations — Elyne Home

[Français](evidence.md) · [Overview](../README.en.md)

## Sources reviewed

- A local Python prototype was identified with voice, memory, scheduler, and IoT-adapter modules.
- The website lists Elyne Home as a proof of concept and shows a visual demonstration. That demonstration does not measure safety, availability, or protocol coverage.

## What this repository does not establish

This repository publishes no whole-home trial, latency measurement, network-segmentation proof, or security qualification. The website's hardware figures describe a target configuration.

**Method:** commercial status, technical description, and test result are different facts. No PASS is claimed without a version, scenario, observation, and reviewable evidence. The internal documents cited informed this summary; their originals are not published here.
